# Personal Staffer design

The native app operates as a quiet work desk. Material components, system typography and predictable keyboard/back behavior provide the interaction vocabulary. The specification's light navy/teal palette governs visual identity. No imagery or fabricated job content is required.

| Token | Value |
|---|---|
| Background | #F5F7FA |
| Surface | #FFFFFF |
| Primary text | #172B4D |
| Muted text | #526175 |
| Accent | #087F8C |
| Border | #D8E0E8 |
| Spacing | 4, 8, 12, 16, 24, 32 logical pixels |
| Control minimum | 48 logical pixels |

At 1000 logical pixels the primary navigation becomes a labeled left rail; smaller windows and Android use five bottom destinations. Settings stays in the app bar. A wide feed opens details beside the retained list. Compact layouts push a full detail screen. Long descriptions are selectable, constrained to readable measure, and scroll independently. Required experience, sponsorship silence, evidence dates and pending/conflict states are written explicitly rather than encoded by color.

Heading roles use Material headline/title typography; labels/body use the platform sans. Text follows OS scale. A restrained teal marks selection and the primary action. Borders separate records without nested decorative cards. Empty source data explains the next meaningful step and never seeds production samples.

Modes: all shipped client screens are Operate; description/evidence reading regions are Read. Native screenshots and real device accessibility checks remain required release evidence; Linux widget rendering alone is not device verification.
